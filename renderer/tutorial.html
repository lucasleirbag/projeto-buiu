Tutorial — Atalhos

Esta janela e o roteiro não aparecem em compartilhamento de tela.

Janela e exibição

AtalhoO que faz
Ctrl + Alt + \Mostrar / ocultar o roteiro
Ctrl + Alt + HAbrir / fechar este tutorial
Ctrl + Alt + QFechar (sair do aplicativo)
Ctrl + Alt + RReiniciar o aplicativo (pânico, se travar)
Ctrl + Alt + ILigar / desligar início automático com o Windows

Mover e redimensionar

AtalhoO que faz
Ctrl + Alt + Shift + SetasMover a janela (segure para continuar movendo)
Ctrl + Alt + CModo configuração: arraste bordas para redimensionar e a barra para mover; aperte de novo para salvar

Transparência

AtalhoO que faz
Ctrl + Alt + =Deixar mais opaca (menos transparente)
Ctrl + Alt + -Deixar mais transparente

Navegar pelo roteiro

AtalhoO que faz
Ctrl + 0Mostrar o roteiro inteiro
Ctrl + 1Parte 0+1 — Setup e commits
Ctrl + 2Parte 2 — Discovery
Ctrl + 3Parte 3 — Fases
Ctrl + 4Parte 4 — Azure DevOps
Ctrl + 5Apêndices — falas técnicas

Dica

Para rolar o roteiro, passe o cursor do mouse sobre a janela e use a roda do mouse — sem precisar clicar.
